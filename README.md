# Detective-Traffic-Sign-TT100k
 The project aims to develop a traffic sign detection system using the Faster R-CNN model. The training and testing data are sourced from the TT100K dataset, which is a diverse collection of traffic signs captured from real-world streets, particularly focusing on traffic environments in China.
 
Link dataset: https://cg.cs.tsinghua.edu.cn/traffic-sign/

Link model: https://drive.google.com/file/d/1gBQ5iVKNTCb3xldXZzr0OE8p6N8JJo86/view?usp=sharing
